# Midi To Chart (Rust)

Welcome to **Midi To Chart!**

This project originally started as a Python application, but I decided to rewrite it in Rust for better performance and a fresh approach to MIDI-to-chart conversion.

The application is functional, although there may still be a few bugs or issues. Improvements and optimizations are always welcome!

## Forking & Contributions

Want to create your own MIDI-to-chart converter or contribute to this project?

You're welcome to fork the repository, experiment with the code, and build upon it!

A few things to keep in mind:
- Please don't claim this project or its original work as your own.
- Don't redistribute modified versions as your own original project.
- Feel free to give credit when using or building upon this project.
- Contributions, suggestions, and improvements are always appreciated!

Credit isn't strictly required, but it's greatly appreciated. :))
